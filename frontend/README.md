# Фронтенд (React + Vite)

Первый срез: авторизация, библиотека персонажей, лист персонажа
(экспорт/импорт JSON). Боевая карта и комната — следующим срезом.

## Запуск

    npm install
    npm run dev

Бэкенд (Flask) должен быть поднят на `http://127.0.0.1:5000` — адрес
API захардкожен дефолтом в `src/api/client.js`, переопределить можно
через `.env.local` (`VITE_API_BASE=...`).

## Тесты

    npm run build   # проверка сборки
    npx vitest run   # интеграционные тесты — ПОДНИМИ БЭКЕНД ПЕРЕД ЗАПУСКОМ,
                      # тесты реально бьют в http://127.0.0.1:5000

## Структура

- `src/api/` — REST-клиент и socket.io синглтон
- `src/store/` — Zustand-сторы (auth, персонажи)
- `src/components/CharacterSheet/` — переиспользуемые кусочки листа
- `src/pages/` — страницы (Login, Library, CharacterSheet)
- `src/utils/dnd.js` — расчёт модификаторов/бонусов (всегда вычисляются,
  никогда не хранятся — см. разбор LSS-схемы)
- `src/styles/tokens.css` — дизайн-токены, две темы: `.theme-parchment`
  (лист персонажа) и `.theme-slate` (будущая боевая карта)
